What a variable is

A variable is a named box that holds a value. The type decides what kind of value fits in the box.

java
int age = 25;

This reads as: type int, name age, value 25.

The primitive types you need now
Type	Holds	                Example
int  	whole numbers,          about -2.1 billion to 2.1 billion	25
long	bigger whole numbers	8_000_000_000L
double	decimal numbers	        19.99
boolean	true or false	         true
char	a single character (single quotes)	'A'

There are also byte, short and float. You'll rarely use them now. String (text, in double quotes) is not a primitive. It is a class, which we'll cover later.
